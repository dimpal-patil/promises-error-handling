Promise API Simulation

A TypeScript project that simulates asynchronous API calls using Promises.

Features
Fetches a mock product catalog.
Fetches reviews for each product.
Fetches a mock sales report.
Uses Promise chaining and Promise.all().
Handles errors using custom NetworkError and DataError classes.
Uses .catch() for error handling and .finally() to indicate completion.
Run

Start the development server and open the local URL shown in the terminal.

Technologies
TypeScript
JavaScript Promises
Vite
